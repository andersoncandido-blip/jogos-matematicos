Movimente o cubo

Cada botão gira uma face em 90°. A letra sem apóstrofo indica giro no sentido horário olhando diretamente para a face; o apóstrofo indica o sentido contrário.

Como jogar

  1. Comece uma nova partida: o cubo será embaralhado.
  2. Use os botões das faces para girar as peças.
  3. O objetivo é deixar cada uma das seis faces com uma única cor.
  4. O cronômetro e a contagem de movimentos começam no primeiro giro após embaralhar.
  5. Use “Desfazer” para voltar um movimento. “Reiniciar” restaura o embaralhamento inicial.

Desafio: tente resolver o cubo usando o menor número de movimentos e melhorando seu tempo!
